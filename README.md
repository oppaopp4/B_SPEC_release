# B_SPEC_release

SSMarkSoft のパチスロゲーム「B_SPEC」の Windows 版リリース用リポジトリです。

- ダウンロード: [Releases](https://github.com/oppaopp4/B_SPEC_release/releases)
- 紹介ページ: https://oppaopp4.github.io/ssmarksoft/B_Spec.html

## 遊び方

1. Releases から `B_SPEC_v1.0.0_win64.zip` をダウンロードして展開します。
2. `B_SPEC_v1.0.0/B_SPEC.exe` を起動します。

操作方法などの詳細は紹介ページ、またはゲーム内メニュー（TABキー）を参照してください。
